Halo Scan

Research decision-support demo — image analysis only, not a medical diagnosis.
This is a software prototype talking directly to the local FastAPI backend. The halo/double-ring pattern is not specific to CSF — saline and other clear fluids can produce the same pattern. Beta-2 transferrin lab testing remains the specific confirmatory method.
